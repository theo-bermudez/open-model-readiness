# Attribution and publication boundaries

The MIT license applies to Theo Bermudez's original project code, documentation and original small test prompts in this public snapshot. The existing local repository had no license file; this release licenses only that original work. It does not relicense models, datasets, dependencies or upstream source material.

The project uses and discusses [NVIDIA AIPerf](https://github.com/ai-dynamo/aiperf), [Ollama](https://github.com/ollama/ollama), and [NVIDIA Nemotron](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Nano-4B-BF16). Their names identify tested software and models, not affiliation or endorsement. Follow each upstream project's license and model terms when installing or downloading it.

Historical benchmarks used AIPerf's ShareGPT loader. Downloadability was not treated as permission to redistribute conversations or generated answers. This release excludes raw datasets, inputs.json, streamed raw exports and mirrored third-party source files. It publishes computed counts, hashes, settings and source locators. These allow inspection and local verification by someone who has the original artifacts, but the hashes alone cannot reproduce the omitted text.

The original local research history is retained unchanged. The public Git history starts from an explicit reviewed snapshot derived from that existing project. No private conversations, terminal transcripts, job-search materials, credentials or personal continuity notes belong in the publication set.

Theo performed the original setup and benchmark runs with Claude Code assistance. Codex assisted with continuation, source inspection, analysis, implementation, validation and publication. AI-generated analysis is checked against recorded observations; it is not substituted for measurements or human labels.
