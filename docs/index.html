READINESS DECISION

Usable for an instrumented local demo.
More evidence needed for deployment.

Verify the mode and output limit, inspect finish reasons, and require a nonempty final answer. These tests support integration fixes—not a production-readiness claim.

THREE FINDINGS

Check the contract before the chart.

01

REQUEST SEMANTICS · WORKAROUND VERIFIED

A string became null. Reasoning stayed on.

AIPerf 0.13.0 converted "none" during extra-input parsing. The intended OFF run still returned reasoning. A loopback proxy preserves the literal API value.

Gate: inspect the serialized request and the returned behavior.

Evidence and workaround →
02

COMPARISON VALIDITY · HISTORICAL RUNS CONFOUNDED

Same seed. Same turns. Different complete prompts.

Generated assistant history changed later requests. Only 6 of 20 complete profiled payloads matched, despite matching conversation order.

Gate: hash the full message array before claiming a fixed-input comparison.

See the prompt audit →
03

ANSWER USABILITY · OUTPUT BUDGET MATTERS

HTTP success can still leave an empty answer.

In the invalid OFF run, 14 of 20 profiled responses had no final answer. Every response hit its length limit.

Gate: distinguish transport success, reasoning output and usable answers.
